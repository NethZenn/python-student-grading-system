# Python Student Grading System

A beginner Python console program for managing student scores and calculating averages.

## Features

* View student data
* Calculate student averages
* Add scores to existing students
* Search for students by name
* Simple menu system

## What I Practiced

* Lists
* 2D lists
* `for` loops
* `while` loops
* `if / elif / else`
* `break` and `continue`
* `sum()` and `len()`
* Functions
* String methods
* Basic input handling

## How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone <your-repository-url>
```

Open the project folder:

```bash
cd python-student-grading-system
```

Run the program:

```bash
python main.py
```
